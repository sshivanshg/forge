# 05 — REST API Specification

- Base path: `/api/v1`. Versioning is in the URL, so breaking changes go to `/api/v2`.
- Auth: `Authorization: Bearer <accessToken>` on everything except `/auth/*`, `/webhooks/*`, and `/actuator/health`.
- Content type: `application/json`. Live streams use `text/event-stream` (SSE).
- IDs are UUIDs. Timestamps are ISO-8601 UTC.
- Interactive docs are generated by **springdoc-openapi** at `/swagger-ui.html`. That is the source of truth once the code exists. This file is the design contract we write *before* coding.

## Error format (RFC 9457 Problem Details)

Every error has the same shape. It is produced in one place, `GlobalExceptionHandler`.

```json
{
  "type": "https://forge.dev/errors/deployment-in-progress",
  "title": "Deployment already in progress",
  "status": 409,
  "detail": "Project 'hello-spring' already has deployment 7f3c… in state BUILDING",
  "instance": "/api/v1/projects/2b1e…/deployments",
  "code": "DEPLOYMENT_IN_PROGRESS",
  "correlationId": "c0a8012e-…"
}
```

Validation errors add `"errors": [{"field": "port", "message": "must be between 1 and 65535"}]`.

## Pagination

`GET` collections accept `?page=0&size=20&sort=createdAt,desc` (`size` max 100) and return:

```json
{ "content": [ … ], "page": 0, "size": 20, "totalElements": 57, "totalPages": 3 }
```

## Auth (`identity`)

| Method | Path | Body | Response |
|--------|------|------|----------|
| POST | `/auth/register` | `{email, password, displayName}` | `201` `{id, email, displayName}` |
| POST | `/auth/login` | `{email, password}` | `200` `{accessToken, refreshToken, expiresIn}` |
| POST | `/auth/refresh` | `{refreshToken}` | `200` new token pair (the old refresh token is revoked: **rotation**) |
| POST | `/auth/logout` | `{refreshToken}` | `204` |
| GET | `/me` | — | `200` `{id, email, displayName, githubConnected}` |

Rules: the password must be ≥ 10 characters. Login failures always return a generic `401 Invalid credentials`, so attackers can't enumerate users.

## GitHub (`source`)

| Method | Path | Notes |
|--------|------|-------|
| GET | `/github/connect` | `302` to GitHub OAuth with a `state` parameter (CSRF protection, stored server-side) |
| GET | `/github/callback?code&state` | Exchanges the code for a token, stores it encrypted, and redirects to the dashboard |
| DELETE | `/github/connection` | Disconnect |
| GET | `/github/repos` | `200` `[{owner, name, defaultBranch, private}]` (cached 5 min in M2) |
| GET | `/github/repos/{owner}/{name}/branches` | `200` `["main", "dev"]` |

## Projects (`project`)

| Method | Path | Body / notes | Response |
|--------|------|--------------|----------|
| POST | `/projects` | `{name, slug?, repoOwner, repoName, branch, rootDir, buildType, port, healthCheckPath, autoDeploy}` | `201` Project. `409` if the slug is taken. |
| GET | `/projects` | paginated | `200` |
| GET | `/projects/{id}` | — | `200` Project incl. `liveUrl`, `liveDeployment` |
| PATCH | `/projects/{id}` | any subset of the create fields except `slug` | `200` |
| DELETE | `/projects/{id}` | Stops runtime instances, then deletes | `204` |

```json
// Project response
{
  "id": "2b1e…", "name": "Hello Spring", "slug": "hello-spring",
  "repo": {"owner": "sshivanshg", "name": "hello-spring"}, "branch": "main",
  "buildType": "AUTO", "port": 8080, "healthCheckPath": "/actuator/health",
  "autoDeploy": true,
  "liveUrl": "http://hello-spring.localhost",
  "liveDeployment": {"id": "7f3c…", "commitSha": "a1b2c3d", "status": "LIVE"},
  "createdAt": "2026-10-06T10:00:00Z"
}
```

## Environment variables (`project`)

| Method | Path | Body | Response |
|--------|------|------|----------|
| GET | `/projects/{id}/env` | — | `200` `[{key, valuePreview: "postg…", updatedAt}]`. Values are **masked**. |
| PUT | `/projects/{id}/env` | `{vars: {KEY: "value", …}}` (upsert) | `204` |
| DELETE | `/projects/{id}/env/{key}` | — | `204` |

Changing env vars does **not** redeploy automatically. The response header `X-Forge-Redeploy-Required: true` tells the UI to show a "Redeploy to apply" banner.

## Deployments (`deployment`)

| Method | Path | Notes | Response |
|--------|------|-------|----------|
| POST | `/projects/{id}/deployments` | Body optional: `{commitSha?}` (default: branch HEAD). Header `Idempotency-Key` (M2). | `202 Accepted` + `Location` header |
| GET | `/projects/{id}/deployments` | paginated history | `200` |
| GET | `/deployments/{id}` | includes the status timeline | `200` |
| POST | `/deployments/{id}/cancel` | only if `QUEUED` or `BUILDING` | `202` / `409` |
| POST | `/deployments/{id}/rollback` | target must have been `LIVE` or `SUPERSEDED` and have an `imageRef` | `202` new deployment |
| GET | `/deployments/{id}/insight` | AI failure analysis (M2) | `200` / `404` |

```json
// Deployment response
{
  "id": "7f3c…", "projectId": "2b1e…",
  "commit": {"sha": "a1b2c3d4…", "message": "fix: health endpoint"},
  "trigger": "WEBHOOK", "status": "HEALTH_CHECKING",
  "imageRef": "registry.localhost:5000/forge/hello-spring:a1b2c3d",
  "failureReason": null,
  "timeline": [
    {"from": null, "to": "QUEUED", "at": "…"},
    {"from": "QUEUED", "to": "BUILDING", "at": "…"},
    {"from": "BUILDING", "to": "DEPLOYING", "at": "…"}
  ],
  "createdAt": "…", "finishedAt": null
}
```

## Logs (`logs`)

| Method | Path | Notes |
|--------|------|-------|
| GET | `/deployments/{id}/logs?after={seq}&limit=500` | Paged history of build and deploy logs |
| GET | `/deployments/{id}/logs/stream` | **SSE**. It first replays from `Last-Event-ID`, then streams live. Events: `log`, `status`, `done`. |
| GET | `/projects/{id}/runtime-logs/stream` | **SSE** of the live container's stdout/stderr |

```
event: log
id: 142
data: {"source":"BUILD","line":"Step 4/9 : RUN mvn -q package","ts":"…"}

event: status
data: {"status":"DEPLOYING"}
```

Because each event carries an `id` (= `seq`), the browser's `EventSource` automatically resumes after a dropped connection by sending `Last-Event-ID`. No log lines are lost.

## Metrics (M2)

| Method | Path | Notes |
|--------|------|-------|
| GET | `/projects/{id}/metrics?range=1h` | CPU, memory, and request rate for the app (proxied from Prometheus) |

## Webhooks (`source`)

| Method | Path | Notes |
|--------|------|-------|
| POST | `/webhooks/github` | No JWT. Verified by the `X-Hub-Signature-256` HMAC. `X-GitHub-Delivery` gives dedup. Only `push` events to a project's configured branch with `autoDeploy=true` trigger a deploy. Always responds `202` fast. The work is queued. |

## Operational

| Path | Notes |
|------|-------|
| `/actuator/health` (liveness/readiness groups) | Used by Docker/K8s probes |
| `/actuator/prometheus` | Scraped by Prometheus (internal network only) |
| `/swagger-ui.html` | API docs (dev profile only) |

## HTTP status codes used

| Code | When |
|------|------|
| 200 / 201 / 204 | Success (read / created / no body) |
| 202 | Accepted for async processing (deploy, cancel, rollback, webhook) |
| 400 | Validation failed |
| 401 | Missing or invalid token |
| 404 | Not found **or not yours** (we don't leak existence) |
| 409 | Conflict: slug taken, deploy in progress, illegal state transition |
| 422 | Semantically invalid (for example, rolling back to a deployment with no image) |
| 429 | Rate limited (M2) |
| 502/503 | Dependency (GitHub, Docker) failed or circuit open |
